Vectris is a hospital patient transport dispatch demo (for educational purposes only) created by Christian Ventura. This dashboard simulates the software a hospital transport dispatcher uses to manage patient transport requests across a hospital. The Transport Queue panel lists requests waiting for a transporter. The status of the request will be shown there. The Assign or View buttons next to the transport requests, allow you to interact with the transport request in real time. The Transport Staff panel shows the available transporters on staff right now and will denote their status (available, on job, on break). Use New Request in the top right to submit a new transport request. Use Dashboard to return to the dashboard.
